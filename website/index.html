Getting started

A few steps. Then you're home.

You need a 64-bit Windows PC. The website provides the download; you use the app on your computer.

  1. 1

    Download and extract

    Download the ZIP above. Choose Extract All in Windows and keep the entire extracted folder together.

  2. 2

    Open Sarah Beauty Desktop

    Inside SarahBeautyDesktop, open SarahBeauty.Desktop.exe. This preview is unsigned and may show a Windows security prompt.

  3. 3

    Enter just three details

    Enter your business name, username, and password, then choose Create my workspace. Your dashboard opens. Add the other information and an optional PIN later in Business settings.

Good to know

A little help before you begin.

Do I need the website admin login?

No. Downloading here requires no admin or GitHub login. Set up your local owner sign-in in the Windows app.

Can I use both a password and a PIN?

Yes. Configure an owner password, then optionally add a 6–12 digit PIN for unlocking. Financial approvals still require the password. Read the password and PIN setup guide.

Will this connect to website bookings?

The desktop app stores its own local records. Downloading it does not import or synchronize website bookings.

Is this the final release?

This is a verified, unsigned Windows preview. Final signing, clean-machine checks, and acceptance on a second device are still pending. Use fictional TEST records while you review it. See the release status before using it for live business records.
