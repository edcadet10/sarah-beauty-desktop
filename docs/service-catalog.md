# Manage services and booking prices

The catalog supplies prices and optional durations for new drafts. Existing booking charges and issued documents keep their copied values.

## Edit a service

1. Open **Service catalog** and search by name or permanent code. Select the service.
2. Enter the unit price and, if known, the duration in whole minutes. Leave an unknown duration blank. Enter zero only for an explicitly free service price.
3. Record the service's tax review status and supporting evidence. A **Reviewed** status requires evidence; it does not assign an actual booking tax rate.
4. Select **Save catalog service**. The new revision retains its owner, time, price, duration, and tax review evidence.
5. Expand **Service price and duration history** to review earlier values. Use **Include archived services** to find or restore an archived definition.

Select **New catalog service** to add a custom definition with its own permanent code. The code stays with that service. The starting bridal package, guest service, travel, and trial portion retain their original unit meanings; create a separate custom service for a different meaning.

The included bridal trial is a package payment portion. It cannot be added as another billable service.

## Use catalog values in a booking

1. Open **Bookings**. Select **New wedding** to copy the current bridal package and included trial portion, or **New booking without a trial** for a separate service plan.
2. Enter the booking name and save its details.
3. Expand **Services and charges**, choose the catalog service and quantity, and select **Add selected catalog service**. Review the copied price and duration. If the catalog changed while the picker was open, refresh the section before adding it.
4. Resolve each charge's actual tax treatment, payer, and any agreed price or discount changes. Save the charge. Catalog tax review alone does not resolve the rate.
5. For a booking without a trial, enter the explicitly agreed deposit after adding its services. Save the details or charge review, then check the displayed deposit and final amounts.

Catalog edits apply to later selections. They do not update an existing booking charge automatically. The booking retains its source catalog revision for review, and an issued quote keeps its saved prices.
