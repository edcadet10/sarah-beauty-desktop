# Project dashboard financial chart data

Eight source-bound tables retain financial scope/basis, monthly figures and activity/closed-coverage flags, aging bands and exact milestone sources, expense categories, cash balances/reconciliation references, cash journal sources, and actual owner movement data. All rows use one captured database, generation, timestamp, and watermark.

Unknown months stay blank; confirmed zero values stay `0`. Aging counts milestone dues once. Contributions, draws, loan principal, and financing cash are not converted into income or allocated profit. Reconciliation ID/hash/date and opening confirmation remain explicit. These are current dashboard datasets at capture; historical financial reports are retained separately in their report tables.

Only selected scalar fields are projected. Raw dashboard/report snapshots and private close-review inputs are excluded. Two new cases and two captured-dashboard cases pass in Release (four targeted) for exact chart values/aging/owner/cash data, unknown months after later activity/lock, stable hashes, captured closed coverage after reopen, and verified reconciliation facts without private review text. Latest complete suite remains 943 before dashboard additions. Upcoming chart data and verified Sheets publication remain pending.
