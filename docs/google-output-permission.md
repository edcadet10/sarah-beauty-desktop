# Authorize each Google output

Status: Revisioned owner destination permission is implemented in the business service. Desktop output controls, actual delivery, and real account acceptance follow separately.

Creating a verified private folder records its connected account generation, current business/instance, random folder binding, observation time, confirming owner, and one audit. Both **Drive archives** and **Sheets export** start disabled. Folder creation alone sends no business data and starts no worker.

An active owner can save the two output choices separately. Enabling either choice rechecks the current protected connection and the folder's actual private ownership/access. Publication rechecks owner access, the entire earlier policy, connection consent, and cancellation. Identical choices retain their revision and audit. Replacing a folder returns both choices to disabled.

Disabling both outputs needs no Google request or usable grant. This permits local withdrawal while offline or after local disconnect. Restored instances, changed connections, changed policy revisions, and deactivated confirming owners cannot reuse earlier permission. A new connection requires a newly reviewed folder; it does not silently adopt an earlier account's destination.

Background permits contain only exact saved policy/connection facts and the chosen output kind. Checking them does not touch a human session or advance the business watermark. A delivery worker must recheck before remote work and before recording completion. Disabling cannot retract a request Google already accepted; uncertain remote results must remain distinguishable from verified success.
