# Preview and deliver a readable Google Sheets export

Open **Backups and recovery**, then expand **Google Sheets readable export**.

1. Enter the financial, planning, and event dates. Preview locally to review captured counts, journal totals, table inventory, and scope notices without Google setup.
2. Connect and verify the intended Google account in the connection controls. Create a private output folder if needed. A replacement folder disables both output choices until saved again.
3. Save the enabled Google Sheets choice. This preserves the separate archive-delivery choice.
4. Export the entered report dates now, or save those dates and an enabled automatic choice with a minimum interval. Dates stay fixed until changed. Automatic delivery requires both saved choices and runs while the app is open.
5. Refresh health/history to review exact captured coverage and attempts. Retry resumes the selected job; it does not silently replace its source. Open the last verified workbook only after a recorded successful delivery.

Report dates select reports; register/history tables cover captured business records. The workbook excludes private notes, sensitivities, credentials, and file binaries. Spreadsheet edits are not imported. A local preview does not freeze later edits or establish delivery. The existing ownership-settings notice remains visible because percentage settings are not implemented yet.

## Preserve edits and cancel work

Navigation preserves unsaved fields. Explicit reload restores saved settings. Saving report settings preserves an unsaved Google choice, and saving Google settings preserves report fields. Only runtime text refreshes on the timer; it does not renew owner access or overwrite edits.

Preview, settings, delivery, and retry use registered cancellable foreground operations. Leaving the view cancels its current operation; the cancel button retains existing files and directs the owner to history. To stop automatic delivery, save its automatic choice off. That withdrawal is checked per scheduled request and inside the final success writer, independently of manual delivery permission.

## Verified scope and pending acceptance

Windows Debug builds with zero warnings/errors. A fresh fictional TEST business previewed all 159 source tables before Google setup, saved one report profile, preserved unsaved edits across navigation, kept an unsaved Google choice during a no-op report save, reloaded settings, blocked unconfigured folder/permission/export/retry/open actions, and preserved separate automatic-on/Google-off choices through lock/close/restart. Read-only checks confirmed watermark 2, one revision-1 profile audit, no financial/document/evidence entries, no Google connection/permission/job/queue, no staged readable files, and valid SQLite integrity/foreign keys.

No real Google request or workbook opening occurred in that walkthrough. Full service tests use a simulated server that stores and rereads actual posted cells. Real Google account, touch/Surface, second-device recovery, and complete release acceptance remain pending.
