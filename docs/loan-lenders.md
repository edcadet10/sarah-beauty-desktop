# Retain a loan's lender identity

1. Open **Resources**, choose the loan register, and create or edit a loan before posting money.
2. Enter its lender/name and actual opening facts. Select **Owner lender** only when an owner actually lent the money. An empty link is not proof that the lender is an external party.
3. Save the loan. A nonzero opening still needs its separate approved financial opening; saving register facts does not post money.
4. Prepare and save a loan opening, proceeds, or repayment in **Money**. Review the captured lender and any owner-lender link before approval.

Changing lender facts after saving a financial draft requires editing, saving, and reviewing that draft again. Approval retains its captured identity. Exact approval retries and linked reversals retain that original identity even if the loan's display name changes later.

After any loan movement has posted, ordinary register editing cannot reassign its owner-lender link. The desktop disables that selector. This protects source attribution; it does not implement an undocumented debt transfer between owners.

Older approved movements without captured lender facts remain unchanged. Reports must identify their historical lender attribution as unconfirmed rather than fill it from today's register. Current names, terms, due dates, and register facts must be labeled separately from historical source facts.
