# Read verified document-decision history

The owner-only reader verifies the retained digest/canonical decision, indexed business/document/version/request/actor/time fields, normalized retry payload hash, and optional evidence identity. It compares the original issued version hash, document kind, decision date, current terminal status, recording-owner business membership, and the exact retained managed evidence descriptor. Historical owner membership does not depend on whether that owner's login remains enabled.

History returns read-only records without changing the business watermark. A known request returns only its matching payload; a conflicting payload is rejected. Reading retained file metadata does not require the original bytes to remain available. A later decision-creation service must independently verify selected evidence contents, and full archive checks must verify every managed file.

Eleven related contract/history Release cases initially passed. All six new history cases pass after adding an evidence-substitution check: actual SQLite reopen with exact issued hash and managed evidence metadata after deleting the original managed bytes, immutable results, matching/conflicting request lookup, changed JSON/payload hash, contradictory current status, locked/foreign access, and a rehashed substituted evidence descriptor. These fixtures insert fictional decisions and status together directly to exercise the read boundary. Authorized transitions, writer retries/rollback, archive/readable integration and desktop controls remain separate work.
